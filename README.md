# Nordic Trivia Tournament

Aplicación React para gestionar un torneo de trivia con múltiples fases de juego en tiempo real.

## Instalación

```bash
npm install
```

## Iniciar

```bash
npm start
```

La aplicación se abrirá en `http://localhost:3000`

## Build Producción

```bash
npm run build
```

## Especificaciones Técnicas

- **Frontend**: React 18 con Hooks
- **State Management**: Context API + Firebase Realtime Database
- **Estilos**: CSS3 (Grid, Flexbox, Animaciones)
- **APIs**: Web Speech API (entrada de voz)
- **Multi-dispositivo**: Sincronización en tiempo real vía Firebase
- **Responsive**: Desktop, Tablet, Mobile

## Características

- Fase 1: Pasapalabras (26 letras)
- Fase 2: Los Nórdicos Dicen (votación)
- Fase 3: Quién Dijo Esto (buzzer en tiempo real)
- Sistema de puntuación global
- Tabla de rankings
- Sincronización multi-dispositivo
